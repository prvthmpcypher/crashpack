Three Frictionless Workflows

Designed for real-world developer terminal workflows.

⚡

Instant Post-Mortem

Run right after a crash. Captures git diffs, runtime versions, packages, docker containers, and system state.

$ npx crashpack
🎯

Command Wrapper

Runs your command live. If it exits with 0, nothing extra is printed. On non-zero exit, it captures logs + full context.

$ crashpack --wrap "npm run dev"
🚰

Piped Log Stream

Pipe any failing build or script directly into crashpack to combine stdout/stderr with environment state.

$ npm test 2>&1 | crashpack --stdin
🛡️ Zero Leaks · Local Only

Mandatory Pass-Through Redaction

Redaction is not an optional end step. Every single collector returns raw text that MUST pass through the redaction engine before reaching output or clipboard.

  • AWS, Stripe, GitHub Tokens & Private Keys: Masked automatically based on gitleaks pattern definitions.
  • Database Credentials & Connection Strings: Passwords inside URI strings are masked (e.g. postgres://user:[redacted]@host).
  • Environment Variables: Only key names are listed. Values are NEVER read, stored, or output.
  • Zero Outbound Network Calls: No analytics, no telemetry, no cloud uploads. Everything stays on your machine.

Built for Speed and Accuracy

⏱️ Sub-2-Second Execution

Runs all collectors concurrently with a strict 2-second timeout per probe. Never blocks or hangs your terminal.

📋 Clipboard + Temp File

Copies straight to clipboard by default, saving a timestamped file outside your repository to prevent accidental git commits.

📦 Manifest & Lockfile Parsing

Parses Node (package.json), Python (requirements.txt, pyproject.toml), Rust (Cargo.toml), and Go (go.mod) with clean truncation.

🤖 AI-Ready Context

Feed the generated markdown directly to Claude, Cursor, ChatGPT, or Antigravity to give agents full diagnostic context in one paste.
